# Kiosk guides

The planner is a web page, so any device with a browser can be the wall display. These guides
cover the setups people actually use:

- [Android tablet / Fire tablet](android-tablet.md) — the cheapest wall display; Fully Kiosk Browser
- [Raspberry Pi + Chromium](raspberry-pi.md) — a Pi driving a TV or monitor, boots straight into the planner
- [Docker on a home server](docker.md) — run the server on a NAS / mini PC, point any screen at it

Orientation: the layout picks portrait or landscape from the screen itself. Mount the display
either way.
